# Inside Qoutes Backend API

Node.js/Express REST API backend for Inside Qoutes app.

## Setup

1. Install Node.js (v14 or higher) from https://nodejs.org/

2. Install dependencies:
```bash
cd backend
npm install
```

3. **Setup Google Gemini AI (Required for Quizzes, Recommended for Advice):**
   
   The app uses Google Gemini AI for:
   - **Quiz Generation**: All quiz questions (Bible verse and Emotions quizzes) are AI-generated in real-time
   - **Personalized Advice**: Generates personalized advice based on user feelings
   
   **⚠️ Important**: Quizzes require Gemini AI - they will not work without it. If you don't set up Gemini for advice, it will fallback to a local AI engine.
   
   To enable Gemini AI:
   
   a. Get your free API key from:
      - https://makersuite.google.com/app/apikey
      - Or: https://aistudio.google.com/app/apikey
   
   b. Create a `.env` file in the `backend` folder:
   ```bash
   cp .env.example .env
   ```
   
   c. Add your API key to `.env`:
   ```
   GEMINI_API_KEY=your_actual_api_key_here
   PORT=3000
   ```
   
   **Note:** The `.env` file is already in `.gitignore` so your API key won't be committed to git.

## Running

### Development (with auto-reload):
```bash
npm run dev
```

### Production:
```bash
npm start
```

The server will run on `http://localhost:3000`

## API Endpoints

### Authentication
- `POST /api/auth/anonymous` - Anonymous sign-in
- `POST /api/auth/logout` - Logout

### User Settings
- `GET /api/users/:userId/settings` - Get user settings
- `PUT /api/users/:userId/settings` - Update user settings

### Quiz Scores
- `GET /api/users/:userId/quiz-scores` - Get all quiz scores
- `POST /api/users/:userId/quiz-scores` - Save quiz score

### Favorites
- `GET /api/users/:userId/favorites` - Get all favorites
- `POST /api/users/:userId/favorites` - Add favorite
- `DELETE /api/users/:userId/favorites/:favoriteId` - Remove favorite

### Profile
- `GET /api/users/:userId/profile` - Get user profile
- `PUT /api/users/:userId/profile` - Update user profile

### Advice (AI-powered)
- `POST /api/advice` - Get personalized advice based on feelings/emotions
  - Body: `{ "text": "I'm feeling happy today", "language": "en" }`
  - Returns: `{ "advice": "...", "detectedEmotion": "happy", "confidence": 0.9, "source": "gemini" }`
  - Uses Google Gemini AI if available, falls back to local AI engine

### Quiz Generation (AI-powered with Gemini)
- `POST /api/quiz/bible-verse` - Generate Bible verse quiz questions using Gemini AI
  - Body: `{ "difficulty": "easy", "count": 5, "language": "en" }`
  - Returns: `{ "questions": [...], "difficulty": "easy", "count": 5, "source": "gemini" }`
  - **Requires Gemini API key** - returns 503 if not configured

- `POST /api/quiz/emotions` - Generate Emotions quiz questions using Gemini AI
  - Body: `{ "difficulty": "easy", "count": 5, "language": "en" }`
  - Returns: `{ "questions": [...], "difficulty": "easy", "count": 5, "source": "gemini" }`
  - **Requires Gemini API key** - returns 503 if not configured

**Note**: All quiz questions are dynamically generated by Gemini AI - no hardcoded questions. Each quiz is unique!

### Health Check
- `GET /api/health` - Check if server is running

## Data Storage

Currently uses JSON file storage (`backend/data/users.json`).

For production, consider using:
- MongoDB
- PostgreSQL
- MySQL
- Supabase

## CORS

CORS is enabled for all origins. In production, configure it properly.

## Connecting Flutter App

Update `lib/services/rest_api_service.dart` with the correct URL:

- **Android Emulator**: `http://10.0.2.2:3000/api`
- **iOS Simulator**: `http://localhost:3000/api`
- **Physical Device**: `http://YOUR_COMPUTER_IP:3000/api`

## Security Notes

- This is a basic implementation for development
- In production, use:
  - JWT tokens instead of UUID tokens
  - Proper authentication middleware
  - Rate limiting
  - Input validation
  - HTTPS
  - Environment variables for sensitive data
